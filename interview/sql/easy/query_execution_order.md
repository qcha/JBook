# Порядок выполнения SQL запроса

## Условие

Расскажите порядок выполнения SQL запроса.

Например, в каком порядке будет логически обработан такой запрос:

```sql
select
    c.country,
    count(*) as users_count
from
    users u
inner join
    cities c
on
    u.city_id = c.id
where
    u.active = true
group by
    c.country
having
    count(*) > 10
order by
    users_count desc
limit 5;
```

## Решение

Важно понимать, что порядок написания SQL запроса и порядок его логической обработки отличаются.

Обычно запрос пишется так:

```sql
select
from
join
where
group by
having
order by
limit
```

Но логически база данных обрабатывает его в другом порядке:

1. `from`
2. `join` / `on`
3. `where`
4. `group by`
5. `having`
6. `select`
7. `distinct`
8. `order by`
9. `limit` / `offset`

Разберем по шагам:

1. `from users u`

    Сначала определяется основная таблица, из которой будут браться данные.

    В нашем примере это таблица `users`.

2. `inner join cities c on u.city_id = c.id`

    После этого выполняется соединение с другими таблицами.

    Условие `on` определяет, какие строки из таблиц нужно сопоставить друг с другом.

    В нашем примере пользователь соединяется с городом по условию:

    ```sql
    u.city_id = c.id
    ```

3. `where u.active = true`

    Затем фильтруются обычные строки.

    `where` отбрасывает строки до группировки и агрегации.

    В нашем примере остаются только активные пользователи.

4. `group by c.country`

    После фильтрации строки группируются.

    В нашем примере пользователи группируются по стране.

    То есть для каждой страны будет сформирована отдельная группа строк.

5. `having count(*) > 10`

    `having` фильтрует уже не отдельные строки, а группы.

    Поэтому в `having` можно использовать агрегатные функции:

    ```sql
    count(*)
    sum(...)
    avg(...)
    max(...)
    min(...)
    ```

    В нашем примере остаются только страны, где больше 10 активных пользователей.

6. `select c.country, count(*) as users_count`

    Только теперь формируется итоговый набор колонок.

    В нашем примере в результат попадут:

    ```sql
    c.country
    count(*) as users_count
    ```

    Именно поэтому алиас из `select` обычно нельзя использовать в `where`: на этапе `where` колонка с этим алиасом еще не сформирована.

7. `distinct`

    Если в запросе есть `distinct`, то на этом этапе удаляются дубликаты из результата.

    В нашем примере `distinct` нет, поэтому этот шаг пропускается.

8. `order by users_count desc`

    Затем результат сортируется.

    В нашем примере страны сортируются по количеству активных пользователей от большего к меньшему.

    В `order by` часто можно использовать алиас из `select`, потому что сортировка выполняется после формирования результата.

9. `limit 5`

    В самом конце ограничивается количество строк в результате.

    В нашем примере будет возвращено только 5 первых строк после сортировки.

При этом важно помнить, что это именно логический порядок выполнения запроса. Реально база данных может выполнить запрос иначе, если оптимизатор найдет более эффективный план.
